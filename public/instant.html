      About this estimate

      Groups models by the colors present at each layer. Minimum mode may use more plates to reduce color changes. Maximum mode finds fewer plates within a batch-wide estimated limit using a bounded search, not a guaranteed optimum. Unknown colors prevent budget mode; minimum mode packs them separately.

      Fixed layer height only. Prime-tower space is estimated separately from the selected print settings. Support filament, slicer painting, variable layers, purge volume and print time are not predicted. Material metadata separates plates; use the appropriate print preset for each material before slicing.
